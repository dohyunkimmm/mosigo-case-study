# MOSIGO Case Study

**웹사이트:** https://mosigo-case-study.vercel.app/

MOSIGO 병원동행 서비스의 전략기획 사례입니다. 문제 정의 → 시장 근거 → 서비스 설계 → 사업성 → 검증 → 결론의 6개 본문 섹션과 최신 데모로 구성합니다.

## 원본과의 연결
- **원본 서비스:** [MOSIGO](https://mosigo-nine.vercel.app/) · [GitHub](https://github.com/dohyunkimmm/mosigo)
- **실제 화면:** 원본 사이트를 직접 임베딩하므로 최신 배포를 표시합니다. 브라우저에서 임베딩을 막으면 새 창 링크를 사용합니다.
- **원본 정보:** 공개 GitHub의 `VERSION`, `main` 커밋 및 `README.md` 주요 기능을 브라우저에서 조회합니다. 원본 README가 갱신되어야 기능 설명도 변경됩니다.
- **전략 본문:** 확인되지 않은 분석·성과가 자동 갱신되지 않도록 별도 관리합니다.

## 디자인
본문은 [Pretendard Variable](https://github.com/orioncactus/pretendard), 이모지 아이콘은 [Tossface](https://github.com/toss/tossface)를 사용합니다. [Tossface 라이선스](https://github.com/toss/tossface/blob/main/LICENSE). 웹폰트 실패 시 시스템 폰트로 대체합니다.

## 자료 구분
경쟁 앱 7종·리뷰 118건은 당시 팀 조사 범위입니다. 사업성 계산기와 KPI는 검증 계획이며 실제 매출이나 사용 성과가 아닙니다. 원본 MOSIGO 저장소는 이 사이트의 편집으로 변경되지 않습니다.

별도 빌드 없이 `index.html`을 배포합니다.
